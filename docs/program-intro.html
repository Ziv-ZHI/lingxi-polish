一、程序概况

程序名称灵犀智磨 BURNISH 协作打磨机器人配套软件系统
英文 / 代号BURNISH（取"打磨、抛光"之意）
程序定位协作打磨机器人的软件层：实时力控 + 工艺管理 + 移动看板一体化
适用对象打磨产线工程师、操作工、设备管理员；iCAN 创新赛道评审
技术形态上位机 Qt（C++，Windows）+ ARM Cortex 控制器（Simulink MBD）+ 微信小程序（移动看板）

二、开发背景与要解决的问题

薄壁件、焊缝、叶片等零件在打磨抛光工序长期依赖人工，存在三方面痛点：

  • 质量一致性差——人手施力波动大，恒力难以稳定，良品率高度依赖师傅经验；
  • 力控难——曲面法向随位姿变化，单靠位置控制易过切或欠磨；
  • 协作安全与可观测性弱——设备状态、告警、工艺参数分散，缺乏统一看板。

本程序让打磨力稳定可控、过程可追溯、状态可移动观测，把"老师傅的手感"沉淀为可复现的力控参数。

三、主要功能模块

上位机（Qt / Windows）：①监控总览（六维力、关节、通信实时遥测）；②力控调参（导纳参数整定与阶跃响应对照）；③轨迹规划（点云分层扫描与插补校验）；④手眼标定（相机内参 + 手眼矩阵 + 六维力重力补偿）；⑤数据分析（A/B 双组对照与指标复核）；⑥工艺库（工艺参数版本管理与下发）。

移动端小程序：设备切换与实时力 hero、生产数据看板、运维工单流转、消息与权限管理；经 MQTT over TLS 上云，写操作均经云端下发并等待回执后才更新界面（不参与 2 ms 实时闭环）。

四、技术架构

上位机Qt（C++），图表用 Qt Charts；与 ARM Cortex 控制器经 UDP 通信，控制器运行 Simulink MBD 生成的 C 代码
实时通信EtherCAT 2 ms 周期；上位机与固件共享协议以 FirmwareProtocol.h 为唯一源
传感与视觉KWR75 六维力传感器；ROS 视觉标定（OpenCV，条件编译 LX_HAVE_*）
云与移动端边缘网关 MQTT/HTTP 上云（QtMqtt 可选降级）；小程序经 MQTT over TLS 订阅看板、下发指令
权限三级操作工（仅执行）/ 工程师（改参数）/ 管理员（管账号）

五、核心算法与创新点

  • 导纳力控：以 τ = M/D 把末端点质量与阻尼映射为导纳参数，让恒定打磨力真实影响响应；内置鲁棒控制器开关做 A/B 对照。
  • 重力补偿：六维力模型 f = m·u + b，u = R(rpy)ᵀ·[0,0,−g]，用正规方程解 m 与零偏，注入噪声下解算无偏。
  • 手眼标定：Eye-in-Hand / Eye-to-Hand 双模式，重投影 RMS 达亚像素级；姿态覆盖度对应手眼方程可观测性。

创新点：①移动端"直连接收、回执驱动"的轻量协同模型，既不绕过 2 ms 实时闭环又保证可观测；②单文件零依赖可运行演示，把整套力控 / 标定 / 工艺能力浓缩为可答辩的闭环证据；③五层软件体系 + 共享协议源，固件与上位机强一致。

六、运行环境与使用方式

  • 上位机：Windows + Qt 运行环境；演示为单文件 monitor-demo.html，任意现代浏览器双击即开，零外部依赖。
  • 移动端：微信小程序（预览以手机外壳 + WeUI 风格呈现），5 个 Tab 内联切换，无二级页 / 弹层。
  • 演示验证结论：连续 60 s 后 RMS 力误差由 2.25 N 降至 0.62 N（改善约 72%）；重力补偿 6 次独立试验负载误差均值 <0.002 kg，残差 ≈ 注入噪声 0.06 N。
