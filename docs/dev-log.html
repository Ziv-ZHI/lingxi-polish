二、项目概述

1.1 项目简介

灵犀智磨 BURNISH 面向薄壁件、焊缝、叶片等零件的协作打磨场景，解决人工打磨质量一致性差、曲面恒力难控、状态不可观测三大痛点。程序以"实时力控—工艺管理—移动看板"一体化为思路：上位机（Qt）实现六维力遥测、导纳力控调参、点云轨迹规划、手眼标定与重力补偿；移动小程序经 MQTT over TLS 上云，提供设备切换、生产看板与工单流转。核心创新在于移动端"回执驱动"的轻量协同模型——写操作经云端下发、收到回执才更新界面，既不绕过 2 ms 实时闭环又保证可观测。验证表明连续运行 60 s 后 RMS 力误差由 2.25 N 降至 0.62 N（改善约 72%），重力补偿解算无偏，可直接支撑答辩与产线落地。

1.2 核心技术 / 方案

  • 架构：五层软件体系——上位机（Qt/C++）、ARM Cortex 控制器（Simulink MBD 生成 C）、EtherCAT 2 ms 实时通信、KWR75 六维力传感、边缘网关上云；上位机与控制器经 UDP，共享协议以 FirmwareProtocol.h 为唯一源。
  • 力控：导纳模型 τ = M/D，把末端质量/阻尼映射为可调参数；内置鲁棒控制器开关做 A/B 双组对照。
  • 标定：六维力重力补偿 f = m·u + b（u = R(rpy)ᵀ·[0,0,−g]），正规方程解 m 与零偏；手眼标定 Eye-in-Hand / Eye-to-Hand 双模式，重投影 RMS 达亚像素级。
  • 移动端：微信小程序（WeUI 风格），5 Tab 内联，写操作走云端回执；STEP 导入依赖 OpenCASCADE、视觉标定依赖 OpenCV，均以 LX_HAVE_* 条件编译。

1.3 创新点

  • ▸ 创新点 1：移动端"直连接收、回执驱动"的轻量协同模型，兼顾 2 ms 实时闭环安全与移动可观测性。
  • ▸ 创新点 2：单文件零依赖可运行演示，把力控 / 标定 / 工艺能力浓缩为可答辩的闭环证据链。
  • ▸ 创新点 3：五层软件体系 + 共享协议源，固件与上位机强一致，便于后续维护与扩展。

1.4 预期成果与应用场景

预期产出：①原型软件 monitor-demo.html（V1.3.0）+ Qt qmake 工程骨架 LingxiPolish/；②软件著作权（计划中）；③力控对照与重力补偿相关论文（计划中）。应用场景：航空航天薄壁件、汽车零部件焊缝、风电/燃机叶片的自动化打磨产线；操作工经移动端看板接收工单与告警，工程师远程调参与标定，管理员统管账号与权限。
